## 目录约定

```text
posts/      已发布文章，按年份归档
drafts/     草稿
assets/     图片和附件，按文章日期或主题归档
templates/  写作模板
```

## 写作流程

1. 在 `drafts/` 写草稿。
2. 定稿后移动到 `posts/YYYY/YYYY-MM-DD-topic.md`。
3. 图片放到 `assets/YYYY-MM-DD-topic/`。
4. 提交 Git commit。
5. 同步发布到 GitHub Pages、知乎、掘金或 LinkedIn。
